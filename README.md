# Data Analyzer and Transformer

## Introduction

Data Analyzer and Transformer is a menu-driven Python project that performs various operations on one-dimensional and two-dimensional lists. It helps users analyze numerical data and apply different transformations using Python functions.

The project covers basic and advanced Python concepts, including recursion, lambda functions, map(), filter(), global variables, and sorting.

## Project Objectives

- To perform mathematical operations on numerical data.
- To analyze 1D and 2D lists.
- To calculate statistical values.
- To understand the use of built-in and user-defined functions.
- To implement recursion and lambda functions.
- To use map() and filter() for data processing.
- To demonstrate *args and **kwargs.
- To understand global variables.
- To return multiple values from functions.
- To create a menu-driven Python application.

## Main Features

### 1. Data Entry
Users can enter numerical values into a one-dimensional list or a two-dimensional list.

### 2. Data Display
Displays the data entered by the user in an organized format.

### 3. Statistical Analysis
Calculates the following information:
- Number of elements
- Minimum value
- Maximum value
- Total sum
- Average

The program uses len(), min(), max(), and sum().

### 4. Functions
Different user-defined functions are used to:
- Calculate the average of values.
- Identify duplicate elements.
- Find unique elements.
- Demonstrate *args and **kwargs.

### 5. Factorial Using Recursion
A recursive function calculates the factorial of a non-negative integer.

Example:
5! = 5 × 4 × 3 × 2 × 1 = 120

### 6. Data Transformation
The program uses lambda functions with map() and filter() to transform and select values based on specified conditions.

### 7. Global Variables
Global variables are used to store data and summary information that can be accessed by different functions.

### 8. Multiple Return Values
A function returns four values:
- Minimum
- Maximum
- Sum
- Average

Each returned value is displayed separately.

### 9. Sorting Operations
The project demonstrates two sorting methods:
- sort() to arrange list elements.
- sorted() to create a sorted list.

Users can arrange numerical values in ascending or descending order.

### 10. Function Documentation
The program uses documentation strings (__doc__) to describe functions. Users can view the documentation through a menu option.

## Technology used

## Installation and Execution

1. Install Python on your computer.
2. Save the program as data_analyzer.py.
3. Open the file using IDLE or another Python editor.
4. Run the program.
5. Choose an operation from the menu.
6. Enter the required numerical data and view the results.

## Sample Input

34 12 56 78 43 21 90

## Sample Output

Total elements: 7

Minimum value: 12

Maximum value: 90

Sum: 334

Average: 47.71

Factorial of 5: 120
